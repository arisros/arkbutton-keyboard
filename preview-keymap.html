Keymap saat ini (sumber: charybdis_handwired.keymap). Ditampilkan urutan visual kiri→kanan seperti yang kamu lihat & pencet — mirror tangan kanan sudah diurus di firmware, jadi apa yang tampil di sini = apa yang keluar. Klik tab layer untuk berpindah.

kiri (central) kanan (peripheral)

Referensi

Cara akses layer

Layer 0 — Base: QWERTY + number row. Pinky kiri = Ctrl. 5 thumb/tangan — kiri: Shift L1 Cmd Space Alt, kanan: Bksp Enter Home L2 Shift. (Posisi thumb terdalam tiap tangan ada di matrix tapi tidak dipasang switch.)

Layer 1 — Numpad: tahan L1 (thumb kiri ke-3). Numpad di kanan, mod + media di kiri.

Layer 2 — Nav/Media: tahan L2 (thumb kanan ke-4). Panah di kiri, media di kanan.

Layer 3 — Adjust/BT: tahan L1+L2 bersamaan → BT_SEL 0–4, BT_CLR, reset.

Warna keycap

▽ = &trans (transparan — jatuh ke layer di bawahnya). ✕ = &none (mati).
